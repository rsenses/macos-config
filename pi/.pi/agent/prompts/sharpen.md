Reformulate this request, without executing it: $ARGUMENTS

Load `ops` for its section 3 brief and section 6 clarification contract. This is a manual preparation command, not authorization to implement.

1. Identify outcome, underlying problem, constraints, preserved behavior and non-goals. Distinguish user decisions, verified facts and assumptions. Deepen, do not broaden: keep unrequested improvements optional, outside acceptance.
2. Use supplied context first; inspect minimal local evidence for concrete uncertainties, not a repository survey. Identify primary sources, methods/tools and observable checks independent of the agent's explanation. Mark proposed sources/checks as unconsulted/unrun.
3. For a missing decision materially affecting behavior, ask one focused question through the question tool or leave it explicitly open; do not choose an implementation to fill the gap. If no request is supplied or recoverable, ask for it.
4. Return a copyable reformulated brief using the existing **Goal**, **Known**, **Evidence**, **Acceptance**, **Checks**, and **Stop** headings. Keep it proportionate to the request; express outcomes and constraints, not an implementation plan.

Do not edit files, save a document by default, launch subagents or other models, design an implementation plan, change plan selection, or invoke `/grill-me` or `/plan` automatically. The user decides whether and how to hand off the brief; direct requests remain valid without this command.
